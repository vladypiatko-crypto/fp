## Music

**[Midnight Drift](music/midnight_drift.mp3)**: a calm instrumental chill-trap / future-bass track
(F minor, 140 BPM half-time, about 2:10). Every sound is synthesized from scratch in
[`music/midnight_drift.py`](music/midnight_drift.py) using only numpy (ffmpeg for the MP3).
Re-render with `python3 music/midnight_drift.py`. A visualizer video is in [`music/midnight_drift.mp4`](music/midnight_drift.mp4).

**[Neon Overdrive](music/neon_overdrive.mp4)**: a fast instrumental riddim track (D minor, 150 BPM, about 1:05).
The first drop hits at 0:06 and the second at 0:17, with four drops in total. Generated by
[`music/neon_overdrive.py`](music/neon_overdrive.py) (`python3 music/neon_overdrive.py`).
